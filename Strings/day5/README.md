# Strings - Day 5

This directory contains the Python string challenges solved on Strings Day 5.

## 📂 Challenges List

*   **[`primes_up_to_n.py`](primes_up_to_n.py)**: Finds and prints all prime numbers from 2 up to N.
*   **[`primes_in_range.py`](primes_in_range.py)**: Finds and prints all prime numbers in the range M to N.
*   **[`descending_number_square.py`](descending_number_square.py)**: Prints a square pattern of descending numbers from N down to 1.

# Strings - Day 4

This directory contains the Python string challenges solved on Strings Day 4.

## 📂 Challenges List

*   **[`number_triangle.py`](number_triangle.py)**: Prints a right-angled triangle of sequential numbers using nested loops.
*   **[`armstrong_numbers.py`](armstrong_numbers.py)**: Finds and prints all Armstrong numbers up to N.
*   **[`number_square.py`](number_square.py)**: Prints a square pattern of sequential numbers from 1 to N.
*   **[`slanted_numbers.py`](slanted_numbers.py)**: Prints a right-aligned slanted column of number S.

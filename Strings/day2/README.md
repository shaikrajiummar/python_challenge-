# Strings - Day 2

This directory contains the Python string challenges solved on Strings Day 2.

## 📂 Challenges List

*   **[`swap_case.py`](swap_case.py)**: Swaps the case of all characters in a string.
*   **[`password_uppercase_check.py`](password_uppercase_check.py)**: Validates if a password contains at least one uppercase character.
*   **[`palindrome.py`](palindrome.py)**: Checks if a string is a palindrome case-insensitively.
*   **[`print_prefixes.py`](print_prefixes.py)**: Prints prefixes of a string of increasing length.
